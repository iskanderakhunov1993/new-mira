## Production exit criteria

- Все P0 имеют `PASS`; `BLOCKED` допускается только для внешней клинической проверки и явно блокирует medical production approval.
- Два аккаунта проверены отдельно; чужие ID не раскрывают существование данных.
- Нет health payload в ProductEvent, URL, логах и Cache Storage.
- Миграции применяются к копии production-схемы без удаления старых колонок/данных.
