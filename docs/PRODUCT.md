# Mira — короткая продуктовая спецификация

## Зачем существует Mira

Mira помогает женщине регулярно фиксировать самочувствие и данные цикла, замечать изменения со временем и готовить понятную информацию для разговора с врачом. Mira не ставит диагноз и не заменяет медицинскую помощь.

## Для кого

Основная пользовательница — женщина репродуктивного возраста, которая хочет понимать свой цикл и симптомы без сложного медицинского интерфейса.

## Основной результат

За минуту в день пользовательница может:

1. понять, где она находится в цикле;
2. отметить важное;
3. увидеть осторожное наблюдение на основе собственных данных;
4. при необходимости подготовить историю для врача.

## Основной поток

`Today → быстрое действие → Diary/Calendar → Analytics → Report`

- **Today** ориентирует и предлагает одно следующее действие.
- **Diary и Calendar** собирают факты.
- **Analytics** показывает паттерны без медицинских диагнозов.
- **Report** превращает историю в материал для консультации.

## Принципы

- Польза раньше количества функций.
- Отсутствие данных не равно нулю.
- Каждое чувствительное поле имеет понятную цель.
- Рекомендации объясняют основание и ограничения.
- Красный флаг направляет за помощью, но не пугает и не диагностирует.
- Интерфейс mobile-first, спокойный и понятный на русском языке.

## Не делаем

- постановку диагнозов;
- обещания медицинской точности прогноза;
- рекомендации начать лекарство без назначения или проверки противопоказаний;
- социальную ленту и механики, не связанные с основным результатом;
- сбор данных «на будущее» без пользовательской пользы.

## Показатели продукта

- доля новых пользовательниц, сделавших первую полезную запись;
- доля недель с 3+ осмысленными записями;
- возврат к просмотру паттернов или отчёта;
- завершение ключевых потоков без ошибок;
- количество обращений к экстренному сценарию отслеживается отдельно и не оптимизируется как engagement.

## Definition of Done

Функция считается готовой, если пользовательский поток понятен, данные сохраняются корректно, предусмотрены пустое/error/loading-состояния, медицинские формулировки безопасны, аналитика событий определена, а подходящие проверки пройдены.
