# Профиль

**Job:** управлять целью, персонализацией, приватностью и своими данными.

| ID | Priority | Status | Task | Outcome |
| --- | --- | --- | --- | --- |
| PROFILE-01 | P1 | done | Цель пользователя: цикл, самочувствие или ПМС | Персонализация имеет явную основу |
| PROFILE-02 | P1 | backlog | Расширенный профиль здоровья | Рекомендации учитывают выбранный контекст |
| PROFILE-03 | P1 | backlog | Центр напоминаний | Пользователь управляет временем и типом уведомлений |
| PROFILE-04 | P0 | backlog | Аудит экспорта, очистки истории и удаления аккаунта | Пользователь полностью контролирует данные |
| PROFILE-05 | P1 | backlog | Отдельный режим планирования беременности | Цель меняет релевантные экраны продукта |
| PROFILE-06 | P2 | idea | Режим беременности как отдельный продуктовый поток | Цикл не смешивается с беременностью |
| PROFILE-07 | P2 | backlog | Код доступа или биометрическая блокировка PWA | Дополнительная локальная приватность |
