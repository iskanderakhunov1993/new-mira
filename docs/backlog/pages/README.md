# Бэклоги страниц Mira

Каждый файл описывает только одну страницу или тесно связанный пользовательский поток.

## Формат задачи

| Поле | Значение |
| --- | --- |
| ID | Постоянный идентификатор, например `CYCLE-01` |
| Priority | `P0`, `P1` или `P2` |
| Status | `idea`, `backlog`, `ready`, `in-progress`, `blocked`, `done` |
| Task | Короткое действие |
| Outcome | Пользовательский результат |

Задачи не удаляются после выполнения: они переходят в `done`. Новая крупная функция перед разработкой получает спецификацию в `docs/features/`.
