# Отчёт для врача P0

## Цель

Помочь пользователю за несколько минут собрать понятные факты для консультации, сохранив контроль над приватными данными.

## Пользовательский поток

1. Пользователь выбирает период: 3, 6 или 12 месяцев.
2. Основные медицинские факты уже выбраны.
3. Дополнительный контекст можно убрать.
4. Личные заметки и интимные данные выключены по умолчанию и включаются только вручную.
5. Пользователь проверяет состав и сохраняет PDF.

## Состав

- циклы и месячные;
- боль и влияние на обычные дела;
- симптомы и отмеченная интенсивность;
- лекарства, эффект и побочные реакции по датам;
- вопросы для обсуждения;
- дополнительный контекст: оценки самочувствия, настроение, сон, личный ритм, контрацепция, домашние тесты и активность;
- приватные заметки и интимные данные только по opt-in.

## Правила данных и безопасности

- Отчёт показывает пользовательские отметки и не ставит диагноз.
- Отсутствие записи не трактуется как отсутствие симптома.
- Для наблюдений указывается основание и минимальный объём истории.
- Mira не отправляет отчёт врачу автоматически.
- Приватные разделы не включаются в новый отчёт без отдельного действия пользователя.

## Критерии приёмки

- На мобильном экране состав разделён на основные, дополнительные и приватные данные.
- Заметки и интимные данные выключены при первом открытии.
- Контрацепция, тесты и активность показаны с датами и значениями.
- PDF содержит только выбранные разделы.
- Пустые разделы не подменяют отсутствие данных нулевым медицинским выводом.
