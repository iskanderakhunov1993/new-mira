# «Мой цикл»: обзор за период

## Цель

Помочь пользователю быстро понять, как менялась продолжительность цикла за выбранный период, и открыть конкретный цикл без сложного медицинского дашборда.

## Пользовательский сценарий

1. Пользователь открывает «Мой цикл».
2. Выбирает 3, 6, 12 месяцев или всю историю.
3. Видит среднюю длину цикла, среднюю длительность отмеченных месячных и диапазон.
4. Сравнивает последний цикл с тремя предыдущими.
5. Нажимает на точку графика и открывает детали этого цикла.
6. При заметном повторяющемся изменении видит один спокойный блок «Обратите внимание».

## Поведение данных

- Учитываются только завершённые циклы.
- Текущий цикл не участвует в средних значениях и диапазоне.
- Отсутствующие данные не отображаются как ноль.
- Сравнение с личной историей появляется только после трёх завершённых циклов.
- Формулировки описывают записи пользователя и не являются медицинской оценкой.
- Надёжность подписывается количеством завершённых циклов.
- На странице показывается не более одного приоритетного наблюдения: повторяющаяся сильная боль, кровотечение больше семи дней или значительное изменение длины цикла.

## Пустые состояния

- 0 циклов: предложить отметить начало месячных.
- 1–2 цикла: показать факты и прогресс до первого сравнения.
- 0 циклов в выбранном периоде: предложить показать всю историю.

## Acceptance criteria

- Выбранный период пересчитывает все три метрики и график.
- По умолчанию выбран период 6 месяцев.
- Точка графика ведёт в детали соответствующего цикла.
- Дублирующий блок сравнения отсутствует: вывод, метрики и график не повторяют друг друга.
- На мобильном переключатель не ломает ширину экрана.
- Lint, domain-тесты и production build проходят.
