# Библиотека знаний P0

## Цель

Помочь пользователю быстро найти понятный материал по текущей ситуации, не создавая впечатление медицинского заключения.

## Пользовательский поток

1. При открытии пользователь видит до трёх материалов, связанных с текущей фазой и сегодняшними отметками.
2. Ниже пользователь выбирает одну из десяти понятных тем.
3. После выбора показываются только материалы этой темы.
4. Поиск работает сразу по всей библиотеке и временно скрывает остальные блоки.
5. Пользователь может сбросить поиск или тему и вернуться на стартовый экран.

## UX-правила

- Не показывать все материалы длинной лентой при первом открытии.
- Причина персональной рекомендации всегда видна.
- Важные симптомы оформляются спокойно, но находятся отдельной темой «Когда нужна помощь».
- Пока редакционный процесс не завершён, не использовать бейджи «Проверено врачом» или «Доказано».
- Текущие материалы обозначаются как редакционные версии.

## Данные и безопасность

- Рекомендации строятся только по сохранённым пользователем отметкам и фазе цикла.
- Рекомендация материала не является диагнозом или индивидуальным назначением.
- Если профиль недоступен, библиотека и поиск продолжают работать.

## Критерии приёмки

- На первом экране нет сплошной сетки из всех статей.
- Поиск по фразам «ПМС», «овуляция», «боль» показывает релевантные результаты.
- Выбор темы ограничивает результаты этой темой.
- Пустой поиск объясняет, что попробовать дальше, и предлагает сброс.
- Интерфейс читается на узком мобильном экране.
