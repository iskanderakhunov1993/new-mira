# Ассистент и профиль Mira — P0

## Цель

Помочь пользователю спокойно разобрать собственные отметки, выбрать безопасный следующий шаг и управлять персонализацией из одного профиля.

## Пользовательский поток

1. Пользователь открывает профиль с Today.
2. Выбирает цель: понимать цикл, следить за самочувствием или наблюдать ПМС.
3. Открывает ассистента Mira.
4. Ассистент показывает один контекстный ответ по сохранённым фактам.
5. Следующее действие ведёт в Инсайты, отчёт, дневник или проверку тревожных признаков.

## Ограничения P0

- Нет свободной генерации медицинских советов.
- Нет постановки диагнозов и назначения лекарств.
- При сильной боли или признаках обильного кровотечения приоритет получает health-check.
- Интимные данные не анализируются без отдельного согласия.
- Данные не передаются внешней AI-модели.

## Критерии готовности

- Ассистент имеет честное пустое состояние.
- Ответ на симптом не называет возможную причину фактом.
- Сильная боль ведёт в `/concerns/pain`.
- Профиль сохраняет выбранную цель через существующий серверный профиль.
- Существующие экспорт, приватность и удаление аккаунта остаются доступны.
