# P0: надёжность дневника и расчётов

## Пользовательский результат

- Снятая в дневнике отметка действительно удаляется из записи выбранного дня.
- Calendar, Today и «Мой цикл» используют один расчёт цикла.
- Инсайты и отчёт строятся только из сохранённых пользовательских фактов.
- Экспорт, очистка истории и удаление аккаунта остаются доступны из профиля.

## Решение

1. `saveEntry` сохраняет частичные обновления по умолчанию.
2. Дневник вызывает его в режиме полной замены дня: пустые скаляры передаются как `null`, списки — как `[]`, флаги начала и окончания месячных — как `false`.
3. Календарный ориентир овуляции и фертильного окна вычисляется из результата `calculateCycle`, а не из второго независимого прогноза.
4. Медицинские предупреждения остаются информационной маршрутизацией и не ставят диагноз.

## Проверка

- Контрактные тесты полной замены дневной записи.
- Тест единого прогноза цикла и календарных ориентиров.
- Полный набор unit-тестов доменной логики и красных флагов.
- Production build.
- Browser smoke для Diary, Insights и Report в demo-режиме.

- Пройти PR/CI и smoke на production после деплоя из `main`.
