# Mira Backlog

Единый индекс продуктовых задач Mira. Детали хранятся по страницам в [`docs/backlog/pages`](./backlog/pages/README.md).

## Как работать

1. Новая идея попадает в бэклог соответствующей страницы.
2. Для задачи указываются ID, приоритет, статус и ожидаемый результат.
3. Перед реализацией задача проходит продуктовый gate.
4. Согласованная крупная функция получает короткую спецификацию в `docs/features/`.
5. После проверки задача отмечается как `done` со ссылкой на PR или commit.

## Статусы

- `idea` — идея ещё не оценена.
- `backlog` — задача оценена, но не запланирована.
- `ready` — объём согласован, можно реализовывать.
- `in-progress` — выполняется.
- `blocked` — есть внешняя зависимость.
- `done` — реализовано и проверено.

## Приоритеты

- `P0` — безопасность, приватность, корректность данных, критический пользовательский поток.
- `P1` — основная продуктовая ценность и удержание.
- `P2` — удобство, расширение и визуальная полировка.

## Ближайший продуктовый фокус

1. `CYCLE-01` — прогноз симптомов на ближайшие семь дней.
2. `CYCLE-02` — объяснение прогноза и уверенности.
3. `CYCLE-03` — изменения относительно личной нормы.
4. `DIARY-01` — применить библиотеку подсимптомов к реальному дневнику.
5. `INSIGHTS-01` — связать активность, контрацепцию и тесты с осторожной аналитикой.
